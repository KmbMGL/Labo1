# Цифровая модель цеха в Unity

Лабораторная работа по курсу «Цифровые модели и двойники».
Цех с ЧПУ-станком, двумя роботами-манипуляторами, двумя конвейерами, складом и автономной тележкой AGV.
Вся сцена строится программно при запуске (Play), поэтому ничего не нужно расставлять вручную.

## 1. Установка

1. Скачать **Unity Hub**: https://unity.com/download и войти (бесплатная лицензия Personal).
2. В Unity Hub: *Installs → Install Editor* → **Unity 6 (6000.x) LTS** или **2022.3 LTS**.
   Отметить модуль *Windows Build Support* (или свою ОС); для кода — *Visual Studio Community* (установится вместе с Unity).
3. Для кода: Visual Studio 2022 с нагрузкой «Разработка игр на Unity» (либо VS Code + расширение *Unity* и .NET SDK).
4. Git: https://git-scm.com/downloads (нужен для выгрузки на GitHub).

## 2. Запуск проекта

1. Unity Hub → *Projects → New project* → шаблон **3D (Built-in Render Pipeline)** или **Universal 3D (URP)**; назвать `Workshop`.
2. Закрыть Unity, скопировать папку **Assets** из этого архива в папку нового проекта (заменить существующую).
   Либо: *Projects → Add → Add project from disk* на распакованном архиве (Unity создаст недостающие папки сам).
3. Открыть проект. Сцена `Assets/Scenes/Workshop.unity` создаётся автоматически
   (меню **Цех → Создать сцену цеха** создаёт её вручную). Открыть её двойным щелчком.
4. Нажать **Play ▶**. Работает в любой пустой сцене, даже если сцену не открывать.

Если на сборке (Build) всё розовое: *Project Settings → Graphics → Always Included Shaders* → добавить `Standard`
(или `Universal Render Pipeline/Lit` для URP). В редакторе (Play) это не требуется.

## 3. Интерфейс редактора Unity (для отчёта)

| Окно | Назначение |
|---|---|
| **Scene** | Редактирование сцены в 3D: перемещение, вращение, масштаб объектов (клавиши Q W E R T) |
| **Game** | Вид из камеры, как увидит пользователь; запуск симуляции кнопкой Play |
| **Hierarchy** | Дерево объектов сцены. Во время Play здесь виден созданный цех: Станок ЧПУ, Робот R1/R2, Конвейеры, Тележка AGV |
| **Inspector** | Свойства выбранного объекта: Transform, компоненты, параметры скриптов |
| **Project** | Файлы проекта (Assets): скрипты, сцены |
| **Console** | Сообщения, предупреждения и ошибки компиляции/выполнения |
| **Toolbar** | Play / Pause / Step, инструменты преобразований, Layers, Layout |

Основные понятия: GameObject (объект), Component (компонент), Transform (положение/поворот/масштаб),
MonoBehaviour (скрипт-компонент), Prefab, Scene, корутина (`IEnumerator` + `yield return`).

## 4. Что смоделировано

* **Помещение**: пол с плитами, стены, колонны, фермы, светильники, жёлтая разметка, ограждение рабочей ячейки, шкафы управления.
* **Конвейер 1** (подача): лента с анимированной текстурой, детали накапливаются перед упором.
* **Робот R1**: поворот основания + 2-звенная рука (плечо, локоть) с **обратной кинематикой**, двухпальцевый захват.
  Берёт заготовку с конвейера 1, несёт к станку и кладёт на стол.
* **Станок ЧПУ**: кожух со стеклом, две раздвижные двери, шпиндель ездит по осям X/Y/Z, вращение фрезы,
  искры (система частиц), подсветка, сигнальная колонна (жёлтый — работа, зелёный — свободен). В детали фрезеруется карман, цвет меняется на синий.
* **Робот R2**: достаёт готовую деталь и кладёт на **конвейер 2**; тот везёт её в тару.
* **Тележка AGV**: едет по разметке между складом, конвейером 1 и тарой, плавно разгоняется и тормозит, поворачивает на месте,
  крутит колёса, мигает маячком. Привозит 4 заготовки со склада, ждёт 4 готовые детали и возвращает их на склад.
* **Интерфейс**: время, счётчик деталей, загрузка станка, состояния устройств, пауза и ускорение x1/x2/x4, сброс, подписи над оборудованием.

## 5. Управление

| Действие | Клавиша / мышь |
|---|---|
| Вращение камеры | перетаскивание мышью |
| Масштаб | колесо мыши |
| Сдвиг | W A S D или стрелки |
| Камеры | 1 общий, 2 станок, 3 R1, 4 R2, 5 слежение за тележкой, 6 сверху |
| Пауза | Пробел |
| Подписи | L |
| Сброс симуляции | R |

## 6. Структура кода (`Assets/Scripts`)

| Файл | Роль |
|---|---|
| `WorkshopBootstrap.cs` | Строит цех, свет, камеру, интерфейс |
| `WorkshopController.cs` | Алгоритм работы: четыре параллельных процесса (корутины), тара |
| `RobotArm.cs` | Обратная кинематика, движение в цилиндрических координатах, захват |
| `CncMachine.cs` | Станок: двери, шпиндель, обработка, искры |
| `Conveyor.cs` | Конвейер: лента, накопление деталей |
| `AgvCart.cs` | Тележка: движение, повороты, колёса |
| `CameraRig.cs`, `Hud.cs` | Камера и экранный интерфейс |
| `Mats.cs`, `Parts.cs` | Материалы (Built-in и URP) и заготовки |
| `Editor/CreateWorkshopScene.cs` | Создание сцены из меню |

Параметры (время обработки `machiningTime`, размер партии `batch`, скорости) доступны в `WorkshopController`, `RobotArm`, `Conveyor`, `AgvCart`.
